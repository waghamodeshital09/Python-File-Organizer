# Python File Organizer

## About
This project automatically organizes files by file type using Python.

## Features
- Organizes files by extension.
- Creates separate folders for different file types.
- Uses Python libraries: os and shutil.

## Technologies Used
- Python
- Jupyter Notebook

## How to Run
1. Open the notebook in Jupyter.
2. Run the code cells.
3. Check the organized folders.
